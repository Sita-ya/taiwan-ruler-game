## 一、資料夾裡有什麼

```
taiwan-ruler-game/
├─ index.html            首頁（兩個大按鈕：我是學生／我是老師）
├─ teacher.html          教師控制台（控制模式＋投影模式）
├─ student.html          學生端（各組平板）
├─ config.js             ★所有數字、文字、教師口白、Firebase 設定都在這裡
├─ style.css             外觀
├─ database.rules.json   Firebase 安全規則（第三章要貼進 Firebase）
├─ js/                   程式（一般不用動）
│   ├─ app.js            共用核心：步驟表、金額計算、籌碼、連線
│   ├─ projection.js     投影畫面
│   ├─ teacher.js        老師端
│   ├─ student.js        學生端
│   ├─ localdb.js        單機模式用的「小型資料庫」
│   └─ qrcode.js         產生 QR code（MIT 授權的開源小工具）
├─ assets/               10 張圖片（原樣使用，沒有改動）
└─ test/                 開發用的自動化測試，上課不需要（可以不上傳）
```

**你只需要會改的檔案只有一個：`config.js`。**

## 二、建立 Firebase（即時同步的免費資料庫）

Firebase 是 Google 的服務，免費方案（Spark）就夠一個班使用。需要一個 Google 帳號。

### 2-1 建立專案
1. 用 Chrome 打開 <https://console.firebase.google.com/>，登入 Google 帳號。
2. 點 **「建立專案」**（或「Create a project」）。
3. 專案名稱隨便取，例如 `taiwan-ruler`，按 **繼續**。
4. 「Google Analytics」那一頁，把開關**關掉**（用不到），按 **建立專案**。
5. 等它跑完，按 **繼續**。

### 2-2 開啟「匿名登入」（必要！）
學生不用輸入任何姓名或帳號，系統會自動給每台平板一個匿名編號，用來確保「一個組別只有一台平板」「學生不能亂改老師的步驟」。

1. 左邊選單點 **「Build（建構）」→「Authentication（驗證）」**。
2. 點 **「開始使用」（Get started）**。
3. 切到 **「Sign-in method（登入方式）」** 分頁。
4. 點 **「Anonymous（匿名）」** → 把 **啟用** 打開 → **儲存**。

### 2-3 建立 Realtime Database
1. 左邊選單點 **「Build」→「Realtime Database」**。
2. 點 **「建立資料庫」（Create Database）**。
3. 位置選 **Singapore (asia-southeast1)**（離台灣最近），按 **下一步**。
4. 安全規則選 **「以鎖定模式啟動」（Start in locked mode）**，按 **啟用**。
   （等一下第三章會換成我們自己的規則。）
5. 建好之後，畫面上方會有一串網址，長得像
   `https://taiwan-ruler-default-rtdb.asia-southeast1.firebasedatabase.app`
   **先複製起來**，第四章要用（這就是 `databaseURL`）。

### 2-4 取得「設定碼」
1. 點左上角齒輪 ⚙️ → **「專案設定」（Project settings）**。
2. 往下捲到 **「您的應用程式」**，點 **`</>`（網頁）** 圖示。
3. 暱稱隨便填（例如 `web`），**不要**勾 Firebase Hosting，按 **註冊應用程式**。
4. 畫面會出現一段程式碼，裡面有 `const firebaseConfig = { ... }`。**先留著這個畫面**，第四章要把裡面的值貼到 `config.js`。
5. 如果裡面**沒有 `databaseURL`** 這一行，就用 2-3 步驟複製的網址。

## 三、貼上安全規則

這一步決定「誰能改什麼」：老師能控制一切；學生只能寫自己那一組的繳費與心情，**不能改步驟、不能搶別組**。

1. Firebase 左邊選單 **「Realtime Database」** → 上方分頁 **「規則」（Rules）**。
2. 用記事本打開本資料夾的 **`database.rules.json`**，**全部選取、複製**。
3. 回到 Firebase 的規則編輯框，**全部選取後刪除，貼上**剛剛複製的內容。
4. 按 **「發布」（Publish）**。看到「規則已發布」就完成了。

> 之後如果你改了 `config.js` 裡的**帳單數量**（現在是 5 張），要同步調整規則裡 `b0`～`b4` 的部分；只改金額、文字不用動規則。

## 四、把設定貼進 config.js

1. 用記事本（或 VS Code）打開 `config.js`。
2. 找到最上面的 `firebase: { ... }`，把 2-4 步驟畫面中的值貼進**引號裡**：

```js
firebase: {
  apiKey: "AIzaSy……",
  authDomain: "taiwan-ruler.firebaseapp.com",
  databaseURL: "https://taiwan-ruler-default-rtdb.asia-southeast1.firebasedatabase.app",
  projectId: "taiwan-ruler",
  appId: "1:123456789:web:abcdef"
},
```

3. 存檔。

> `apiKey` 不是密碼，放在網頁裡是正常的；真正的保護是第三章的安全規則。

## 五、免費上線：GitHub Pages 或 Netlify

要把整個 `taiwan-ruler-game` 資料夾（**包含 assets 資料夾**）放到網路上，學生的平板才打得開。二選一即可，**Netlify 最簡單**。

### 方法 A：Netlify（拖曳上傳，最簡單）
1. 打開 <https://app.netlify.com/drop>（可用 Google 帳號註冊登入）。
2. 把整個 **`taiwan-ruler-game` 資料夾**用滑鼠**拖進**網頁中間的虛線框。
3. 幾秒後會得到一個網址，例如 `https://funny-name-123.netlify.app`。
4. （選填）網站設定 → **Change site name**，改成好記的名字，例如 `taiwan-ruler`。
5. 之後如果改了 `config.js`，回到該網站的 **Deploys** 分頁，再把資料夾拖進去一次即可更新。

**學生網址**：`https://你的網站.netlify.app/student.html`
**老師網址**：`https://你的網站.netlify.app/teacher.html`

### 方法 B：GitHub Pages
1. 到 <https://github.com> 註冊登入 → 右上角 **＋ → New repository**，名稱例如 `taiwan-ruler-game`，選 **Public**，按 **Create repository**。
2. 在新倉庫頁面點 **「uploading an existing file」**，把資料夾裡的**所有檔案和資料夾**（`index.html`、`teacher.html`、`config.js`、`js`、`assets`…）拖進去。
   注意：要拖「資料夾裡面的內容」，不是外面那一層；`assets` 也要一起拖。
3. 下方按 **Commit changes**。
4. 倉庫上方 **Settings → Pages → Build and deployment**：Source 選 **Deploy from a branch**，Branch 選 **main**、資料夾 **/(root)**，按 **Save**。
5. 等 1～2 分鐘，重新整理該頁，上方會出現網址：`https://你的帳號.github.io/taiwan-ruler-game/`。

**學生網址**：`https://你的帳號.github.io/taiwan-ruler-game/student.html`

> 小提醒：學生平板可以先在課前把學生網址加到主畫面或書籤，上課時只要點開、輸入 4 位數代碼。老師也可以只印一張 QR code 貼在平板盒子上——投影幕上的 QR code 掃了就會自動帶入代碼。

## 六、上課當天的操作流程

### 課前 5 分鐘
1. 老師的筆電連上電子白板（螢幕「延伸」或「複製」都可以，**複製**最簡單）。
2. 打開老師網址 `…/teacher.html`。
   - **第一次**：會要求你**設定教師密碼**（至少 4 個字，只存在這台電腦的瀏覽器裡）。
   - 之後每次打開都輸入這個密碼。
3. 按 **「🌐 連線模式：開新的一局」**。系統產生 **4 位數房間代碼**。
4. 右上角看到 **🟢 已連線**，表示一切正常。

### 步驟 0：大廳（學生加入）
1. 按上方的 **「📽 投影模式」**，白板上會出現大標題、房間代碼和 QR code。
2. 學生拿平板，掃 QR code（或打開學生網址 → 輸入代碼）→ **選組別**（1～N）。
3. 投影幕上的「第 N 組」會變成 **✔ 已加入**。
4. 平板會在這時**預先載入圖片**，所以之後翻牌很順。
5. **預設就是 6 組**（A～F 六個家庭：小芳家是 A 類型、小傑家是 C 類型，所以 6 組時會有 2 個「邊緣戶」家庭）。要改成 4 或 5 組，在控制模式右下角 **⚙️ 設定** 的「本局組數」選；也可以改 `config.js` 的 `defaultGroups`。計算模式、補助方式也在這裡調整。**組數要在抽籤前設定**。
6. 6 組時畫面的差異：身分卡一列 6 張、各組現況排成 3×2、「大反轉」頁會並排顯示小美家與小傑家。

### 逐步控制
- 控制模式有 **「◀ 上一步」「下一步 ▶」**，按鈕上的字會告訴你「按下去會發生什麼」（例如「🎲 抽籤」「公布第 2 張帳單」「💰 發放補助」）。
- 左邊是**步驟列表**，點哪一步就直接跳到哪一步。
- 右邊上方是**教師口白提示**（說什麼、提醒什麼），只有老師看得到。
- 右邊中間是**各組即時狀態**：哪組已加入、線上或離線、目前帳單繳了沒、餘額多少。
  - 帳單／命運事件階段，**全部組別都繳完時「下一步」會變綠色閃爍**。
  - 某組平板壞了或慢了：按該組的 **「代繳」**，或按 **「全部代為繳費」**。
  - 某組選錯或要換平板：按 **「踢出」**，他們可以重新選組，原本的紀錄會保留。
- **投影模式快捷鍵**：`→` 或 `空白鍵` ＝ 下一步、`←` ＝ 上一步、`P` ＝ 全班暫停、`C`（或左上角淡淡的小按鈕）＝ 回控制模式。
- **「⏸ 全班暫停」**在最上面最顯眼的位置。按下去，所有學生平板立刻蓋上「👀 眼睛看老師」，完全無法操作；再按一次解除。
- **學生永遠無法自己前進或後退**——步驟只有老師能改。

### 全部步驟一覽
| 步驟 | 老師做什麼 | 學生平板 |
|---|---|---|
| 0 大廳 | 顯示代碼與 QR | 選組別，等待 |
| 1 抽身分卡 | 先「進入」，再按「🎲 抽籤」 | 卡片翻牌，顯示家庭與月收入、籌碼 |
| 2 生活大扣血 | 逐張「公布第 n 張帳單」 | 先算「繳完還剩多少」→ 答對 → 繳費（籌碼飛出去） |
| 3 命運事件 | 「🃏 抽命運卡」 | 同一張卡，一樣算完再繳費 |
| 4-1 紅線登場 | 長條圖＋紅線動畫 | 顯示自己「在線下／在線上」 |
| 4-2 發放補助 | 「💰 發放補助」 | 在線下的家庭收到補助、債務還清 |
| 4-3 大反轉 | 放大小美家 | C 類型家庭收到「不符合資格」通知 |
| 4-4 說說心情 | 顯示心情與統計，再說明「邊緣戶」 | 選心情／寫一句話後送出 |
| 5 世界的尺 | 4 頁（3 美元／約 90 元／世界地圖／SDG 1） | 請看大螢幕 |
| 6 總結 | 兩把尺 | 完整收支紀錄 |
| 隱藏：第二條線 | 左側步驟列表最下面的橘色按鈕（第四節課用） | 請看大螢幕 |

### 地圖頁（5-3）
- 地圖是原圖，**沒有加框、加字、裁切**（底部的資料來源保留）。
- 點一下地圖可以**放大**，再點一下**縮回**；放大後可以用滑鼠拖曳移動。
- 右下角的「🌏 開啟互動地圖」會用新分頁開啟 Our World in Data。若 `config.js` 的 `worldMapUrl` 留空，按鈕就不會出現。

### 下課後
- 控制模式右下角 **「🆕 開新的一局」** 會產生新代碼（下一個班用）。
- 想清掉資料：Firebase 控制台 → Realtime Database → 資料 → 把 `rooms` 刪掉。（系統本來就不會存任何姓名；超過 12 小時的舊房間代碼也會被自動覆蓋。）

## 七、單機投影模式（網路不穩時的備援）

學校網路掛掉、或 Firebase 還沒設定好時用這個。**步驟、數字、畫面和連線版完全一樣**，只是沒有學生端。

1. 打開 `teacher.html` → 輸入教師密碼 → 按 **「🖥 單機投影模式（不連線）」**。
   （就算沒有網路、沒設定 Firebase，這個模式也能用。）
2. 各組改用**實體籌碼**（1 個硬幣＝1,000 元、1 張鈔票＝10,000 元）。
3. 老師用 `→` 或「下一步」推進，白板會自動顯示每組的金額（單機模式假設每組都有正確繳費）。
4. 4-4 說說心情：改成請 C 組**口頭**分享。
5. 資料只存在這台電腦的瀏覽器裡。重新整理頁面，會回到原本的步驟。要重來就按 **「⏮ 重新開始」**。

> 小技巧：網頁一次載入後會快取圖片；課前先連網打開一次，上課時就算網路變慢也比較穩。

## 八、怎麼修改數字、文字、教師口白

全部在 **`config.js`**。用記事本打開，改完存檔、重新上傳（Netlify 重新拖曳／GitHub 重新上傳這個檔案）、重新整理網頁。

| 想改什麼 | 找這個區塊 |
|---|---|
| 家庭的名稱、介紹、月收入、代表色、圖片 | `families` |
| 帳單的項目、金額、圖示、備註 | `bills`（金額、文字、圖示都能改；**張數建議維持 5 張**，因為安全規則是照 5 張寫的） |
| 命運事件的文字、金額 | `fate` |
| 最低生活費、家庭人數、中低收入戶數字 | `line` |
| 補助是「剛好補到 0」還是「固定金額」 | `subsidy`（上課時也可以直接在老師的「設定」裡改） |
| 計算模式預設開或關 | `calcMode`（上課時也可在「設定」裡開關） |
| 畫面上的說明文字、提問、總結文字 | `texts` |
| **教師口白提示** | `notes`（`say` ＝可以說的話，`tip` ＝提醒） |
| 地圖頁的互動地圖網址 | `worldMapUrl`（留空 `""` 就不顯示按鈕） |

小提醒：
- 文字要放在**半形引號 `" "`** 之間，每行最後的**逗號不要刪**。
- 改錯了網頁變空白？打開瀏覽器的開發者工具（F12）看 Console 的紅字，通常是少了逗號或引號。
- 「邊緣戶（C 類型）」的判斷是：**收入沒有低於紅線，但只比紅線多不到 `marginalGap`（預設 5,000 元）**。
- 判斷是否符合低收入戶用 **46,545 元**（15,515 × 3）；畫面上寫的「約 46,500 元」只是方便閱讀。
- 補助預設「剛好補到 0」：A、E 類型補 10,000，B 類型補 18,000。

## 九、常見問題

**Q1　老師頁面說「Firebase 還沒開啟匿名登入」**
→ 回第二章 2-2，確認 Anonymous 已「啟用」。

**Q2　出現 `auth/unauthorized-domain` 或「這個網域未授權」**
→ Firebase 控制台 → Authentication → Settings → **Authorized domains** → **新增網域**，填你的網站網域（例如 `xxx.netlify.app` 或 `你的帳號.github.io`）。

**Q3　出現「沒有權限」（PERMISSION_DENIED）**
→ 第三章的規則還沒貼或沒按「發布」；或是老師在「不是原本開房的電腦」上操作。

**Q4　學生輸入代碼後說「找不到房間」**
→ 確認代碼 4 位數沒打錯；確認老師已經按了「開新的一局」；學生網址要和老師用的是同一個網站。

**Q5　某組選組別時說「已有人」，但其實是他們自己的平板**
→ 這台平板的瀏覽器資料被清掉（或改用另一個瀏覽器）。老師在「各組即時狀態」按該組的 **「踢出」**，他們就能重新選。

**Q6　學生平板斷線或重新整理**
→ 連上之後會**自動回到老師目前的步驟、同一組、原本的繳費紀錄**，不會重來。

**Q7　老師筆電重新整理或當機**
→ 重新打開 `teacher.html` → 輸入密碼 → 按 **「↩ 繼續上次的房間」**，步驟和學生都還在。**要用同一台電腦、同一個瀏覽器。**

**Q8　忘記教師密碼**
→ 在老師的瀏覽器清除這個網站的資料（Chrome：設定 → 隱私權 → 刪除瀏覽資料，勾選「Cookie 與其他網站資料」），重新打開頁面就能重新設定。

**Q9　學生答案打不出負數**
→ 數字鍵盤上有「−」鍵：先按「−」，再按數字。

**Q10　聲音**

## 十、隱私與安全說明

- **不蒐集任何個資**：學生只選組別，不輸入姓名；匿名登入的編號只用來辨識「這是哪台平板」。
- 心情的「自訂一句話」最多 40 字，會顯示在白板上。若有不適合的回應，在「各組即時狀態」按 **「隱藏回應」**，白板就不會顯示。
- 資料庫裡只有：房間設定、目前步驟、抽籤結果、各組的繳費紀錄與心情選擇、哪些組別已加入。
- 安全規則重點（`database.rules.json`）：
  - 只有「開房間的那台電腦」能改步驟、設定、抽籤、暫停、踢人。
  - 學生只能寫自己那一組的：繳費紀錄（而且只能繳「已公布」的帳單）、心情（只有 4-4 開放時）、在線狀態。
  - 同一個組別只能被一台平板佔用。
